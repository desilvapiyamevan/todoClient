# TodoClient

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 21.2.24


## Running unit tests

Run `ng test` to execute the unit tests via [Jasmine]
ng test --include='**/todo.service.spec.ts'

Install:

MOQ, xUnit and Microsoft.NET.Test.Sdk for Backend tests

## Running end-to-end Application

Open the Application on VS code

1. Open Split Terminals
2. To run client
    2.1. cd todoClient
    2.2. ng serve
3. To run API backend
    3.1 cd todoApi
    3.2 dotnet run
    3.3 dot net 10
4. Open browser and browse "http://localhost:4200/"

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
